## Slide 5

- A
- ACE  /  NEXTGEN
- VALIDATION & NEXT STEPS
- 05  /  05
- Validate fast. Build lean. Measure real value.
- A practical Round 1 plan that turns a promising idea into evidence-backed product direction.
- 01  DISCOVER
- Day 1
- Test ACE app on available devices. Capture 3–5 genuine screenshots. Interview 8–12 students across branches / years.
- 02  PROTOTYPE
- Day 2
- Build a clickable profile → match → saved timeline flow. Run 5 short usability tests and note where users hesitate.
- 03  IMPROVE
- After feedback
- Fix the top friction point first. Compare task completion and comprehension before adding complexity.
- SUCCESS METRICS
- TIME
- to find a relevant opportunity
- FIT
- % who identify eligibility correctly
- ACTION
- save rate + task completion
- TRUST
- reminder opt-in + opt-out
- FEASIBLE MVP + TRUST BY DESIGN
- Build:
- profile preferences + transparent rule-based matching + saved-item store + notification scheduler.
- Protect:
- collect only needed data; editable/deletable preferences; reminders opt-in.
- Be honest:
- show official source links and flag eligibility details that need confirmation.
- “Make ACE the place students don’t just find opportunities — they follow through.”
